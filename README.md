NexusMIDI Pro
​DAW e Aplicativo Android de Alta Performance voltado para MIDI, SoundFonts (.sf2 / .sf3) e Controladores Hardware via USB e BLE Nativo.
​Recursos Principais
​Sintetizador SoundFont Multitimbral baseado em SpessaSynth (AudioWorklet).
​Conectividade MIDI Completa: Suporte a dispositivos USB MIDI físicos e Bluetooth Low Energy (BLE) com plugin Android nativo otimizado.
​Interface Estilo Studio Console: Controles de Faders, Master FX, EQ, Compressor e Teclado/Pads responsivos (Modo Retrato e Paisagem otimizados).
​Persistência Local: Armazenamento de SoundFonts pesados via IndexedDB.
